Codex 是 AI 编程助手 CLI，可在终端中辅助理解代码、生成修改与执行测试。Windows 环境应按当前工具文档配置沙箱和权限，采用满足任务需要的最小权限；不应将某台机器的策略限制推广为通用要求。

委托 coding agent 前，应明确目标、允许访问的目录、验收标准和禁止项。模型与推理参数由工具版本和项目需要配置；不能以开发工具的总结替代真实文件与测试证据。

任务结束后，使用 git diff 检查修改，使用 pytest 或项目测试工具验证结果，并核对进程已退出。遇到卡住时先保留产物和日志，只处理可确认归属本任务的进程。
