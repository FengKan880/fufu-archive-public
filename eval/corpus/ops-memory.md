Agent 记忆可保存经用户授权的稳定事实与偏好；技能保存可复用的方法、操作步骤与工作流。检索系统应区分事实记录、程序性知识、原始会话和临时任务状态，避免混淆来源与可信度。

记忆条数或上下文预算满了时，可以合并重复条目、标记过期知识，并将长文放到外部知识库后按需检索。删除或覆盖原文前应先确认授权与恢复能力，不能仅凭摘要就丢弃来源。

MEMORY.md、USER.md 与技能文件是可能的宿主接口示例，实际注入策略和容量由宿主配置决定。数据库只提供存储、检索和审核机制，不规定某个用户的个人记忆优先级。
