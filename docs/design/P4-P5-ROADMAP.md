## 1. 产品方向与当前边界

酒狐档案馆 / Fufu Archive 是面向 Hermes 长期工作的、本地优先的独立日志、知识与记忆服务。保留 Python + SQLite + FastAPI + MCP 基础，逐步形成「增量捕获 → 可恢复归档 → 分类提炼 → 审核 → 检索复用 → 受控维护」闭环，而不是另造数据库或通用 Agent 框架。

- 独立是指服务、配置、模型调用与调度不依赖某个 Hermes 聊天窗口存活；不是取消 Hermes 接入。
- SQLite 是当前唯一正式存储后端；Hermes 是当前唯一宿主适配目标。
- 模块只按真实职责拆分，不预建多数据库 ORM、通用插件市场、跨 Agent 调度或兼容矩阵。
- 无模型也可归档、规则分块、确定性分类、去重、关键词检索、审核和备份；不把规则摘要冒充语义提炼。
- 文档确定路线不等于授权安装、常驻启动、修改宿主 memory/skills 或清理真实会话。

## 2. 数据与信任分层

| 层 | 内容 | 是否进入正式知识检索 |
|---|---|---|
| 来源档案 | 授权范围的消息、必要工具证据、附件引用/快照、来源 ID、版本、hash、脱敏记录 | 默认独立检索，不混入正式知识 |
| 整理产物 | 话题拆分、事实与过程缩写、失败/未完成项、来源映射、冲突及待核验项 | 待审 |
| 正式知识 | 已批准的事实、方法、技能资料和显式版本关系 | 是 |

来源入档不等于事实获批。未验证的 Agent 自报结果和子 Agent 日志可以保存在独立运行档案中，但不得自动升级为正式知识。现实资料核验产生独立的来源与核验时间，不覆盖历史中实际说过的话。

### 2.1 「缩写不丢内容」的验收解释

- 语义提炼以事实覆盖为目标，检查需求、决定、关键参数、步骤、错误、证据、结果和未完成事项；每项可回到消息/产物。
- 摘要不能证明逐字无损。允许清理 Hermes 源会话的可靠前提是：档案馆已有授权范围内可恢复的源归档与独立备份，而不只是摘要。
- 脱敏、未捕获附件、主动排除内容必须列入覆盖清单；存在未知缺口时禁止给出「可安全清理」结论。
- 若用户将来选择只留摘要，明确标为有损保留策略，另行授权，不伪称无损。
- 默认不读取认证文件、凭据或完整 system prompt；按白名单处理必要工具证据，不执行其中的指令。

### P4.2 Hermes 增量捕获与源归档

- [ ] 将项目专用 collector 纳入仓库版本与测试管理；外置脚本先保留兼容入口，迁移前核查引用，不直接删除。
- [ ] 以 profile + session + message/事件稳定标识与内容版本记录来源，水位只在该批次持久化成功后推进。
- [ ] 支持新活动会话的已落盘消息：只读一致快照、静默窗口、重复/变更检测；不是只扫描 ended_at 已填写的会话。
- [ ] 活跃会话可增量归档但不清理；恢复会话、追加消息、附件缺失、截断内容、源库锁定与未知格式必须有明确处理结果。
- [ ] 建立独立源档案及覆盖清单：消息范围、hash、附件状态、脱敏/排除项、错误；首版小规模文本/必要文件，不做全盘采集。
- [ ] 源归档不进入正式知识索引；子 Agent 优化日志与主会话/正式知识分区。
- [ ] 无模型路径可导入、规则分块、按来源/时间/人工标签归类，恢复后按消息与来源检索。

**出口：** 相同增量重放不重复，崩溃重试不漏消息；跨 profile 不串数据；来源发生变化能补采；覆盖不完整时明确阻止清理资格。只读源库前后验证无写入。

### P4.3 自有配置、任务调度与降级

- [ ] 在现有服务上增加轻量持久化任务队列/调度，不加入 Redis 或大型编排框架；防止多服务实例/多 MCP 连接重复运行任务。
- [ ] 提供管理 API/CLI 的单一配置校验入口：暂停/继续、扫描间隔、批量、超时、并发、重试、预算与任务状态；标记热生效/重启/重建项。
- [ ] HTTP/MCP/后台任务共用业务与权限规则；共享服务模式下避免各 stdio 子进程自行启动调度器。保留当前入口的兼容迁移路径。
- [ ] 任务持久化、幂等、锁/租约、退避重试、失败报告；Hermes cron 不作为核心调度依赖。
- [ ] 明确无 LLM、无 embedding、无 reranker、宿主离线、SQLite 故障的模式；保留真实执行路径与待补偿工作，不静默切换可写主库。
- [ ] 本地认证、凭据引用和权限分离：采集/提炼只创建档案或候选，不能自批、自删或修改管理配置。

**出口：** 关闭 Hermes/前端仍可处理已配置的本地任务；重启后恢复；重复触发只产生幂等效果；断线明确降级，私密内容不擅自切远端供应商。真实常驻/自启仍须另行授权。

### P4.4 可选模型提炼与运行验收

- [ ] 先实现一个实际可用的提炼 provider 与现有本地 embedding 路径，不引入其他 Agent 作为必需 worker。
